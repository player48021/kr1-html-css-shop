## Описание проекта

Учебный многостраничный сайт интернет-магазина, разработанный на чистом HTML и CSS без использования CSS-фреймворков. JavaScript применяется минимально — только для открытия/закрытия модального окна и валидации формы заявки.

Проект демонстрирует:

- семантическую HTML-разметку;
- единую навигацию между страницами и якорные ссылки;
- Flexbox и CSS Grid;
- CSS-переменные и состояния `:hover`, `:focus-visible`, `:disabled`;
- БЭМ-именование классов;
- базовое позиционирование: `relative`, `absolute`, `fixed`, `sticky`, `z-index`;
- таблицу характеристик товара;
- форму заявки и модальное окно.

## Позиционирование

- `position: sticky` — шапка сайта;
- `position: relative` — карточка товара (контейнер для бейджа);
- `position: absolute` — бейдж в карточке;
- `position: fixed` — кнопка «Наверх»;
- `z-index` — модальное окно, фиксированная кнопка, бейдж.
